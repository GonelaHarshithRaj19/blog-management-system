## Features

### User Side
- View all blogs dynamically from MySQL database
- Blog detail page
- Responsive blog cards
- Blog images
- AJAX category filter
- AJAX date filter
- AJAX search without page reload

### Admin Side
- Admin login system
- Add new blog
- Edit existing blog
- Delete blogs
- Manage categories and blog content

SQL file included:
blog_system.sql

---

## Setup Instructions

1. Clone or download the repository

2. Import the SQL file into phpMyAdmin

3. Update database credentials in:
db.php

4. Place project folder inside:
htdocs/

5. Run Apache and MySQL using XAMPP

6. Open in browser:
http://localhost/blog-system/
